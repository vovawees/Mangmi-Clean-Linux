# Credits

Mangmi Clean Linux stands on the shoulders of these projects:

| Project | What we use | License |
|---|---|---|
| [ROCKNIX](https://github.com/ROCKNIX/distribution) | SM6115 kernel patches, Mangmi Air X device trees, kernel config, ALSA UCM profiles, InputPlumber device/capability maps, WirePlumber tuning, emulator default configs and hotkey layout | GPL-2.0 |
| [ROCKNIX extra-firmware](https://github.com/ROCKNIX/extra-firmware) | device firmware blobs (downloaded at build time, never committed) | proprietary / redistributable |
| [OpenABL](https://github.com/OpenHandheldCollective/OpenABL) | UEFI-capable Android boot loader replacement that boots Linux from SD | GPL-3.0 |
| [Linux](https://kernel.org) | kernel | GPL-2.0 |
| [Arch Linux ARM](https://archlinuxarm.org) | base distribution and package repositories | various |
| [linux-msm](https://github.com/linux-msm) | qrtr, pd-mapper, rmtfs, tqftpserv | BSD-3-Clause |
| [Mesa](https://mesa3d.org) | Freedreno / Turnip drivers | MIT |
| [ES-DE](https://es-de.org) | console mode frontend | MIT |
| [RetroArch / libretro](https://www.libretro.com) | emulation frontend and cores | GPL-3.0 and others |
| [InputPlumber](https://github.com/ShadowBlip/InputPlumber) | gamepad composition, desktop mouse mode | GPL-3.0 |
| [KDE Plasma](https://kde.org/plasma-desktop/) | desktop mode | GPL / LGPL |
| [Sway](https://swaywm.org) | console mode compositor | MIT |
