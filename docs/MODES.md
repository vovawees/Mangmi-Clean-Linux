# Режимы: «Консоль» и «ПК»

Mangmi Clean Linux — гибрид. Один пользователь, одни и те же файлы и игры, два интерфейса.
Последний выбранный режим запоминается и запускается при следующем включении.

## 🎮 Консоль (по умолчанию)

- Минимальный Wayland-композитор **Sway** в режиме киоска + **ES-DE** на весь экран — ничего лишнего
  в памяти, максимум ресурсов игре.
- Игры запускаются через `mangmi-run`: на время игры включается профиль производительности для этой
  системы (например, PS2 → *max*), тяжёлые эмуляторы закрепляются за быстрыми ядрами Cortex-A73,
  игра работает в отдельном cgroup `games.slice` с повышенным приоритетом CPU/IO (и замораживается во сне).
- Системное меню ES-DE **Mangmi Air X**: режим «ПК», профили производительности, вентилятор,
  подсветка стиков, обновление системы.

## 🖥 ПК

- **KDE Plasma 6** (Wayland), Firefox, Dolphin, Konsole, Kate, Ark, Gwenview, Spectacle, магазин
  **Discover** (Flatpak / Flathub), экранная клавиатура.
- Встроенные контролы автоматически становятся мышью и клавиатурой:

  | Контрол | Действие |
  |---|---|
  | Левый стик | курсор мыши |
  | Правый стик, L1 / R1 | прокрутка |
  | A или R2 | левая кнопка мыши |
  | B или L2 | правая кнопка мыши |
  | Y | Enter |
  | X | Esc |
  | Start | меню приложений |
  | Крестовина | стрелки |

  **Guide + L3** переключает «мышь ↔ геймпад» (например, чтобы играть в Steam Link или
  Flatpak-игры прямо из режима «ПК»).
- Через USB-C хаб работают клавиатура, мышь, флешки и внешние диски; по Bluetooth — геймпады,
  наушники и клавиатуры.

## Как переключаться

| Откуда | Как |
|---|---|
| Везде | удерживать **Guide + Select** 1,5 секунды |
| Консоль | ES-DE → система *Mangmi Air X* → **Desktop Mode** |
| Консоль (с клавиатурой) | `Ctrl+Alt+Backspace` |
| ПК | значок **Game Mode** на рабочем столе или в меню |
| Терминал | `mangmi-mode console` / `mangmi-mode desktop` / `mangmi-mode toggle` |

Переключение закрывает текущий сеанс (несохранённые данные в открытых программах будут потеряны)
и за пару секунд запускает другой.

## Только консоль

Нужен только игровой режим? Соберите образ `console` (`IMAGE_FLAVOUR=console`, см. [BUILD.md](BUILD.md)):
без KDE Plasma, Firefox и прочих программ рабочего стола — меньше места и быстрее обновления.
Переключатель режима в нём просто ничего не делает.
