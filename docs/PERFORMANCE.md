# Производительность

Snapdragon 662: 4 × Cortex-A73 (2,0 ГГц, ядра 4–7) + 4 × Cortex-A53 (1,8 ГГц, ядра 0–3), GPU Adreno 610.
Всё в системе настроено так, чтобы игре доставалось максимум этих ресурсов.

## Профили (Guide + →, ES-DE → Mangmi Air X, `mangmi-ctl perf …`)

| Профиль | CPU | GPU | Для чего |
|---|---|---|---|
| `powersave` | schedutil, до 70 % частоты | до 60 % | 8/16 бит, чтение, видео — максимум автономности |
| `balanced` (по умолчанию) | schedutil, весь диапазон | simple_ondemand, весь диапазон | большинство игр |
| `performance` | минимум 50 % частоты | минимум 55 % | PSP, N64, DS, Dreamcast, Saturn, 3DS |
| `max` | performance (всегда максимум) | performance (до 1050 МГц) | PS2, GameCube, Wii |

Во время игры профиль выбирается **автоматически по системе** и возвращается обратно после выхода.
Значения по умолчанию: PS2/GameCube/Wii → `max`; 3DS/Saturn/Dreamcast/PSP/N64/DS → `performance`;
PS1 → `balanced`; остальные — текущий профиль. Изменить:

```sh
mangmi-ctl perf game ps2 performance   # PS2 впредь запускать с профилем performance
mangmi-ctl perf balanced               # профиль системы вне игр
mangmi-ctl status                      # частоты, температуры, вентилятор, батарея
```

Статус и настройки хранятся в `/var/lib/mangmi/hwd.json` (служба `mangmi-hwd`).

## Вентилятор (Guide + ←)

`auto` (кривая по температуре SoC), `quiet` (тише, допускает более высокую температуру), `cool`
(раньше и сильнее), `max`. Перегрев защищён ядром: троттлинг по штатным trip-точкам работает всегда.

## Что уже сделано в системе

- **Ядро** Linux 7.2 с патчами ROCKNIX, собрано под Cortex-A73/A53, без initramfs
  (корень монтируется сразу), отключены дорогие mitigations, `nowatchdog`, PREEMPT, MGLRU.
- **Память:** zram-своп размером с ОЗУ (lz4 — самый быстрый кодек на этих ядрах), `vm.swappiness=100`,
  без проактивной компакции, ранняя небольшая запись на SD (нет многосекундных подвисаний).
- **Хранилище:** BFQ + read-ahead 1 МБ для microSD (быстрее грузятся ISO, интерфейс не «залипает»),
  ext4 `noatime`, `commit=30`.
- **Игры:** `mangmi-run` закрепляет PS2/GC/Wii/Saturn/3DS за ядрами A73, cgroup `games.slice` с высоким
  весом CPU/IO; прерывания (GPU, дисплей, USB, накопители, геймпад) разведены на ядра A53, чтобы не мешать игре.
- **Графика:** Mesa Freedreno (GLES 3.2) и Turnip (Vulkan), кэш шейдеров до 2 ГБ, Wayland без X11
  (XWayland только для старых программ).
- **Консольный режим** — Sway-киоск вместо полного рабочего стола: в разы меньше памяти и фоновой
  нагрузки, чем у KDE Plasma.
- Нет лишних служб: только NetworkManager/iwd, Bluetooth, PipeWire, InputPlumber, `mangmi-hwd`.

## Советы

- Карта **A2/U3** заметно ускоряет загрузку игр и ES-DE. Медленная карта — самая частая причина «тормозов».
- PS2, GameCube, Wii, 3DS — на пределе возможностей SoC: многие игры идут полноскоростно в родном
  разрешении, но не все. Используйте `max`, без апскейла, с включёнными «speedhacks» эмулятора.
- PS1: PCSX ReARMed (по умолчанию, самый быстрый) или DuckStation (точнее, Vulkan, апскейл до 2×).
- Для сравнения/отладки производительности: Guide + B в RetroArch показывает FPS.
