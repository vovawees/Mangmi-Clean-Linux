# Горячие клавиши

**Guide** — центральная кнопка Mangmi (с логотипом). Все системные комбинации начинаются с неё.

## Система (работают везде: в ES-DE, в играх, на рабочем столе)

| Комбинация | Действие |
|---|---|
| Guide + ↑ / ↓ | яркость экрана |
| Guide + → | следующий профиль производительности (стики мигают цветом профиля) |
| Guide + ← | следующий режим вентилятора: авто → тихий → охлаждение → максимум |
| Guide + R3 | следующий режим подсветки стиков |
| Guide + L3 | геймпад ↔ мышь и клавиатура |
| Guide + Select (держать 1,5 с) | переключить режим «Консоль» ↔ «ПК» |
| Guide + Start (держать 1,5 с) | принудительно закрыть зависшую игру / эмулятор |
| Громкость + / − | громкость |
| Power (коротко) | сон; ещё раз — проснуться |
| Power (долго) | выключение |

## RetroArch (во время игры)

| Комбинация | Действие |
|---|---|
| Guide + Start | выйти в ES-DE |
| Guide + Y (верхняя) | меню RetroArch |
| Guide + R1 | сохранить состояние |
| Guide + L1 | загрузить состояние |
| Guide + R2 | ускорение (вкл/выкл) |
| Guide + A (нижняя) | пауза |
| Guide + X (левая) | скриншот (в `~/Pictures`) |
| Guide + B (правая) | показать FPS |

Короткое нажатие Guide + Start корректно закрывает RetroArch (с сохранением SRAM), а удержание
1,5 с — «жёсткое» закрытие для любой программы.

### Меню RetroArch

Меню упрощено: тема Ozone «Nord», крупный шрифт, язык системы. **A** (нижняя) — выбрать,
**B** (правая) — назад, как в ES-DE. В меню игры (Guide + Y) остались только нужные пункты:
продолжить, перезапустить, закрыть, сохранить/загрузить состояние, скриншот, параметры ядра,
управление и шейдеры. В настройках — изображение, звук, управление, сохранения, экранные
уведомления, интерфейс и RetroAchievements. Всё скрытое включается в *Настройки → Интерфейс →
Видимость пунктов меню* (или *Показать расширенные настройки*).

## Отдельные эмуляторы

У отдельных эмуляторов (DuckStation, PPSSPP, melonDS, ARMSX2 — ставятся по кнопке *Install*) свои горячие клавиши (настраиваются в их меню
«Настройки → Управление / Горячие клавиши»). Универсальный выход из любого из них —
**Guide + Start (держать 1,5 с)**: эмулятор закрывается, вы возвращаетесь в ES-DE.

## Подсветка стиков

Режимы: `battery` (цвет = заряд, по умолчанию), `static`, `breath`, `rainbow`, `wave`,
`thermal` (цвет = температура), `off`. Тонкая настройка в терминале:

```sh
mangmi-ctl led static            # режим
mangmi-ctl led color ff3080      # цвет (RRGGBB или red/green/blue/cyan/magenta/yellow/orange/purple/pink/white)
mangmi-ctl led brightness 40     # яркость, %
mangmi-ctl status                # текущее состояние железа
```
